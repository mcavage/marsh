# Third-party software

marsh is licensed under Apache-2.0 (`LICENSE`, `NOTICE`). It builds on the
following.

## Brush (vendored, MIT)

marsh compiles the shell from source vendored under `vendor/brush/`, pinned to
commit `1389a8e8af6bec56fdfb9ab60a8c898bc14aa961` of
<https://github.com/reubeno/brush> (`vendor/brush/UPSTREAM_REVISION`).
Brush is MIT-licensed; its license is `vendor/brush/LICENSE`. marsh's local
changes are a patch queue in `docs/upstream/brush/` (see its README for the
order and purpose of each patch). marsh does not run Bash to implement the
shell.

## Rust crates

Host and guest binaries link the crates in `Cargo.lock`. `make install` and the
release tarball install their license texts as
`share/licenses/marsh/THIRD-PARTY-NOTICES.txt` and
`rust-package-notices.json`, generated by `scripts/third-party-notices.py`.
Crates whose published packages omit a required text get it from
`packaging/notice-overrides/`. Guest binaries carry the same notices in
`libexec/marsh/licenses/marsh/`.

## Container images

The shell image and the Kit images are built on Docker Hardened Images
(`dhi.io/sbx-templates`, `dhi.io/debian-base`), pinned by digest in
`packaging/shell-image` and the Kit Dockerfiles under `kits/`. They add
agent CLIs and their ACP adapters (Claude Code, Codex, Pi, and npm packages
locked in each Kit's `package-lock.json`). Each image carries its notices; the
canonical collection they are built from is `packaging/dhi-notices/collected/`.
Release CI publishes these images to `docker.io/mcavage/marsh-*`; see
[docs/design/supply-chain.md](docs/design/supply-chain.md#published-images).

Agent CLIs keep their own terms. In particular, Claude Code is distributed by
Anthropic under its own license, not under Apache-2.0; installing marsh does not
grant rights to it.

## Not distributed

marsh does not bundle or modify Docker Sandboxes (`sbx`). Install it from
Docker.
