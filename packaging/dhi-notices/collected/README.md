# Upstream notices and source materials

These are retained upstream license texts, copyright notices and source
materials for software included in marsh images. They are shipped as original
attributions, not a generated assertion about a particular image or dependency
version. Original Debian and npm notices also remain with their packages.

Dependency updates do not regenerate this directory or require a license-delta
approval. Version pins, Cargo/npm lockfiles, immutable base-image references,
and runtime smoke tests are the build controls.
